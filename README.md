# FKNGYM Public

Public website and legal pages for FKNGYM.

## Pages

- `https://fkngym.com/` - app landing page
- `https://fkngym.com/privacy/` - Privacy Policy

## GitHub Pages

Publish this repository from the `main` branch root in GitHub Pages settings.

Custom domain:

```txt
fkngym.com
```

The `CNAME` file should stay in the repository root so GitHub Pages keeps the
custom domain after deploys.

The site is a plain static page:

- `index.html`
- `privacy/index.html`
- `styles.css`
- `script.js`
- `assets/`
- `CNAME`
